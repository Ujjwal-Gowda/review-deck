The CSS mental models that stop layout from feeling like guesswork.

The box model

Every element is a box: content, then padding, then border, then margin. Always set *, *::before, *::after { box-sizing: border-box; } so width includes padding and border. Vertical margins between blocks collapse (the larger one wins).

The cascade: which rule wins?

  1. !important (avoid it)
  2. specificity: inline style > #id > .class / [attr] / :hover > element
  3. later in the source wins a tie

Keep specificity low and flat (single classes). :where() has zero specificity; cascade @layers order whole stylesheets.

Layout: pick the right tool

/* Flexbox: ONE dimension (a row or a column). Navbars, toolbars, centring */
.toolbar { display: flex; gap: 8px; align-items: center; justify-content: space-between; }
.center  { display: grid; place-items: center; }     /* the easiest centring */

/* Grid: TWO dimensions. Page layouts, card grids */
.cards { display: grid; grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); gap: 16px; }
.page  { display: grid; grid-template: "side main" 1fr / 300px 1fr; }

/* Positioning */
.badge  { position: absolute; top: 8px; right: 8px; }  /* relative to the nearest positioned ancestor */
.header { position: sticky; top: 0; }
.modal  { position: fixed; inset: 0; }

Responsive design

.layout { padding: clamp(16px, 4vw, 48px); }            /* fluid values instead of breakpoints */
@media (max-width: 900px) { .side { display: none; } }  /* viewport-based */
.card-list { container-type: inline-size; }
@container (min-width: 500px) { .card { display: flex; } }   /* based on the COMPONENT's size */
@media (prefers-color-scheme: dark) { :root { --bg: #131417; } }
@media (prefers-reduced-motion: reduce) { * { animation: none !important; } }

Things that confuse everyone

  • Stacking contexts: z-index: 9999 can't escape a parent that has transform, opacity < 1 or its own z-index. Stacking is per context.
  • Percentage heights need a parent with a defined height. In flex or grid, add min-height: 0 so children can scroll.
  • Custom properties (--brand: #2FA24F) are inherited and live at runtime. That's how this site's light/dark theme works.
  • Animate only transform and opacity (chapter 65).
67.1 basic Build a responsive product grid: 1 column on phones, as many 220px-minimum columns as fit on larger screens, with no media queries.

display:grid; grid-template-columns: repeat(auto-fill, minmax(min(220px, 100%), 1fr)); gap:16px;. The min() prevents overflow on very narrow screens.
