Writing Dockerfiles that build fast, produce small images, and run safely.

# Node app: multi-stage build
FROM node:22-slim AS deps
WORKDIR /app
COPY package.json package-lock.json ./          # copy the lockfile FIRST: this layer is cached until deps change
RUN npm ci

FROM deps AS build
COPY . .                                         # source changes only invalidate from here down
RUN npm run build && npm prune --omit=dev

FROM node:22-slim AS runtime                     # final image: no compilers, no dev deps, no source
WORKDIR /app
ENV NODE_ENV=production
COPY --from=build /app/node_modules ./node_modules
COPY --from=build /app/dist ./dist
USER node                                        # never run as root
EXPOSE 8080
HEALTHCHECK CMD node -e "fetch('http://localhost:8080/healthz').then(r=>process.exit(r.ok?0:1))"
CMD ["node", "dist/server.js"]                   # exec form: the app is PID 1 and receives SIGTERM
# Go: a static binary on an empty image (~10 MB total)
FROM golang:1.26 AS build
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -ldflags="-s -w" -o /app ./cmd/api
FROM gcr.io/distroless/static-debian12
COPY --from=build /app /app
USER nonroot
ENTRYPOINT ["/app"]

Rules

  • Order for caching: things that rarely change first (base image, system packages, dependency manifests), then source code.
  • .dockerignore: node_modules, .git, .env, dist, out. That keeps the build context small, and keeps secrets out of the image.
  • Combine update and install in one RUN and clean up in the same layer: RUN apt-get update && apt-get install -y --no-install-recommends curl && rm -rf /var/lib/apt/lists/*.
  • Never COPY .env or put secrets in ENV/ARG: they're readable in the layers forever. Use build secrets (RUN --mount=type=secret) or runtime env vars.
  • CMD vs ENTRYPOINT: ENTRYPOINT is the executable; CMD is the default arguments (overridable by docker run image args).
Security lens · Dockerfiles

Secrets baked into image layers are recoverable forever: use build secrets. Run as non-root, pin base images by digest, and keep the image minimal.
