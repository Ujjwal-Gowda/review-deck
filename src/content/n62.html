Sockets: the programming interface

import socket
srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)       # TCP
srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
srv.bind(("0.0.0.0", 9000)); srv.listen()
conn, addr = srv.accept()                                      # blocks until a client connects
data = conn.recv(1024); conn.sendall(data.upper()); conn.close()
# test from another terminal:  echo hello | nc localhost 9000

A connection is identified by 4 values: (src IP, src port, dst IP, dst port). That's how one server port handles thousands of clients. TCP is a byte stream, not messages: one send can arrive as two recvs, or two as one, so protocols add framing (length prefixes, newlines, HTTP headers).

62.1 think Why is the first request to a new server slower than later ones on the same connection?

DNS lookup, then the TCP handshake (one round trip), then the TLS handshake (1–2 more round trips), and TCP slow-start begins with a small send window. Keep-alive and connection pooling reuse the connection to skip all of that.

Security lens · TCP/IP

Every listening port is attack surface. Check ss -ltnp, and bind internal services to 127.0.0.1 or a private interface, never 0.0.0.0 on a public host.
