Classical ML with scikit-learn: often the right tool for tabular business data.

import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_absolute_error

df = pd.read_csv("daily_sales.csv")                   # predict tomorrow's units per product per store
X = df[["store_id", "product_id", "dow", "is_festival", "units_lag_7", "units_lag_1", "price"]]
y = df["units"]
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, shuffle=False)   # time series: DON'T shuffle
model = HistGradientBoostingRegressor(max_iter=300).fit(X_tr, y_tr)
print("MAE:", mean_absolute_error(y_te, model.predict(X_te)))
print("baseline (last week's value):", mean_absolute_error(y_te, X_te["units_lag_7"]))   # always compare to a naive baseline

  • Feature engineering (lags, day of week, holidays) usually matters more than the choice of model.
  • Metrics: MAE/RMSE for regression; precision, recall, F1 and ROC-AUC for classification (accuracy misleads on imbalanced data); a confusion matrix.
  • Leakage: features that wouldn't be known at prediction time (e.g. using tomorrow's data) produce fake great scores.
  • Cross-validation (time-series splits for temporal data) for honest estimates.
