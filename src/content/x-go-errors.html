Go's explicit error handling: creating, wrapping and inspecting errors, and using defer, panic and recover correctly.

Errors are values

func LoadStock(path string) (map[string]int, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, fmt.Errorf("load stock: %w", err)          // %w WRAPS: the original stays inspectable
    }
    defer f.Close()
    stock := map[string]int{}
    sc := bufio.NewScanner(f)
    for line := 1; sc.Scan(); line++ {
        sku, qtyStr, ok := strings.Cut(sc.Text(), ",")
        if !ok { return nil, fmt.Errorf("%s:%d: missing comma", path, line) }
        qty, err := strconv.Atoi(strings.TrimSpace(qtyStr))
        if err != nil { return nil, fmt.Errorf("%s:%d: bad qty: %w", path, line, err) }
        stock[sku] = qty
    }
    return stock, sc.Err()                                     // don't forget the scanner's own error
}

Three kinds of error values

var ErrOutOfStock = errors.New("out of stock")                // 1. sentinel: compare with errors.Is

type ValidationError struct{ Field, Reason string }           // 2. custom type: carries data, match with errors.As
func (e *ValidationError) Error() string { return e.Field + ": " + e.Reason }

return fmt.Errorf("reserve %s: %w", sku, ErrOutOfStock)        // 3. wrapped: adds context

if errors.Is(err, ErrOutOfStock) { suggestAlternative() }      // true even if wrapped several times
var ve *ValidationError
if errors.As(err, &ve) { respond(400, ve.Field) }
if errors.Is(err, fs.ErrNotExist) { useDefaults() }            // standard-library sentinels

Rules of thumb

  • Handle an error or return it with context, never both (no log-and-return at every layer).
  • Error messages are lowercase with no final punctuation, because they get chained: load stock: stock.csv:3: bad qty: invalid syntax.
  • Never discard errors with _ unless you can explain why; errcheck/staticcheck flag it.
  • errors.Join(err1, err2) combines several errors (for example, from validating many fields).

panic and recover

func mustParseConfig(s string) Config {        // "Must" functions panic: only for startup or programmer errors
    c, err := parse(s); if err != nil { panic(err) }; return c
}
func safeHandler(h http.HandlerFunc) http.HandlerFunc {   // recover at a boundary so one bad request can't kill the server
    return func(w http.ResponseWriter, r *http.Request) {
        defer func() {
            if v := recover(); v != nil { slog.Error("panic", "err", v); http.Error(w, "internal error", 500) }
        }()
        h(w, r)
    }
}

Panics are for bugs and impossible states (an index out of range, a nil map write). Expected failures (missing file, bad input, network down) are error values.
