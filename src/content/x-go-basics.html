How a Go program is organised, and Go's types, zero values, constants and conversions.

Anatomy of a program

package main                        // every file belongs to a package; "main" + func main() = an executable

import (
    "fmt"
    "os"
    "strconv"
)

const taxPercent = 5                // untyped constant

func main() {
    if len(os.Args) < 2 {
        fmt.Fprintln(os.Stderr, "usage: bill AMOUNT_PAISE")
        os.Exit(2)
    }
    amount, err := strconv.Atoi(os.Args[1])
    if err != nil {
        fmt.Fprintln(os.Stderr, "amount must be a whole number:", err)
        os.Exit(1)
    }
    fmt.Printf("total: ₹%.2f\n", float64(amount*(100+taxPercent))/10000)
}

Unused variables and unused imports are compile errors, and gofmt decides the formatting, so every Go codebase looks the same.
