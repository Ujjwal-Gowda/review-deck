Stable networking in front of ever-changing pods.

apiVersion: v1
kind: Service
metadata: { name: api }
spec:
  selector: { app: api }          # all ready pods with this label become endpoints
  ports: [{ port: 80, targetPort: 8080 }]
  type: ClusterIP                  # default: internal only
TypeReachable from
ClusterIPinside the cluster, at api.default.svc.cluster.local (or just api within the namespace)
NodePortevery node's IP on a high port (30000–32767): mostly for dev
LoadBalancerthe cloud provisions an external load balancer
Headless (clusterIP: None)DNS returns the individual pod IPs (StatefulSets)

A Service gives a stable virtual IP and DNS name, and load-balances across the ready pods matching its selector. When pods are replaced, the endpoints update automatically. Debug with kubectl get endpoints api: an empty list means the selector doesn't match your pod labels, or no pod is ready. For quick local access: kubectl port-forward svc/api 8080:80.
