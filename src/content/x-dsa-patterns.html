Three patterns that turn "check every pair" (O(n²)) into a single pass (O(n)).

1. Two pointers

Move two indices toward each other, or in the same direction, instead of nesting loops.

def pair_with_sum(sorted_prices, budget):        # two items whose prices add to exactly budget
    i, j = 0, len(sorted_prices) - 1
    while i < j:
        s = sorted_prices[i] + sorted_prices[j]
        if s == budget: return i, j
        if s < budget: i += 1                    # need more: move the small end up
        else: j -= 1                             # need less: move the big end down
    return None
[100, 150, 200, 350, 400] budget 550 i j 500 < 550 → i++ i j 550 → found (150, 400)

Same-direction pointers: remove duplicates in place, partition, and fast/slow pointers on linked lists (Linked Lists).

2. Sliding window

Keep a window [left, right] over the array: grow it on the right, shrink it from the left, and update the answer as it moves.

def max_sales_in_k_days(sales, k):               # FIXED window size
    window = sum(sales[:k]); best = window
    for i in range(k, len(sales)):
        window += sales[i] - sales[i - k]        # slide: add the new day, drop the oldest
        best = max(best, window)
    return best

def longest_without_repeat(s):                   # VARIABLE window size
    seen, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1                   # shrink past the previous copy
        seen[ch] = right
        best = max(best, right - left + 1)
    return best

3. Prefix sums

Precompute running totals once; then any range sum costs O(1).

sales = [3, 1, 4, 1, 5, 9, 2]
prefix = [0]
for x in sales: prefix.append(prefix[-1] + x)    # prefix[i] = sum of the first i items: [0,3,4,8,9,14,23,25]
def range_sum(i, j): return prefix[j + 1] - prefix[i]   # sum of sales[i..j]
range_sum(2, 5)   # 4+1+5+9 = 19 = 23 − 4

Extensions: 2-D prefix sums (the sum of any rectangle in a grid), difference arrays (add v to a whole range in O(1), then take one prefix sum at the end), and "subarray sums equal to K" (prefix sums + a hash map of the sums seen so far).
