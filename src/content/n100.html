Using an ORM productively without losing sight of the SQL it generates.

// Prisma: schema-first, generated client
const orders = await prisma.order.findMany({
  where: { storeId: 7, status: "paid" },
  include: { items: true, customer: { select: { name: true } } },   // ONE query plan, no N+1
  orderBy: { createdAt: "desc" }, take: 20,
});
await prisma.$transaction(async tx => {
  await tx.stock.update({ where: { sku: "milk" }, data: { qty: { decrement: 2 } } });
  await tx.orderItem.create({ data: { orderId: 42, sku: "milk", qty: 2 } });
});
const rows = await prisma.$queryRaw`SELECT sku, sum(qty) FROM order_items GROUP BY sku`;   // escape hatch (parameterised)

// Drizzle: SQL-shaped, typed, thin
const rows2 = await db.select().from(orders).where(and(eq(orders.storeId, 7), eq(orders.status, "paid"))).limit(20);

The N+1 problem

const orders = await prisma.order.findMany();                  // 1 query
for (const o of orders) o.customer = await prisma.customer.findUnique({ where: { id: o.customerId } });  // +N queries ✗
// fix: include/join, or batch: WHERE id IN (…) and map the results in memory

Turn on query logging in development (new PrismaClient({ log: ["query"] }), SQLALCHEMY_ECHO) and watch for repeated queries.

ApproachExamplesTrade-off
Full ORMPrisma, TypeORM, SQLAlchemy ORM, Django ORM, GORMfast CRUD, migrations included; can hide slow queries, and complex SQL gets awkward

Connection pooling: ORMs keep a pool per process. In serverless, each invocation can open new connections and exhaust Postgres, so use a pooler (PgBouncer, Prisma Accelerate, Neon's pooler).

Security lens · ORMs

ORMs parameterise by default, but raw-query escape hatches and dynamic orderBy fields built from user input reintroduce injection. Allow-list sortable fields.

Practice

100.1 basic Turn on query logging in an ORM project and find an N+1. Fix it with an include or join and count the queries before and after.

Before: 1 + N queries (one per row). After: 1–2 queries. The logs make it obvious, so check them for every new list endpoint.
