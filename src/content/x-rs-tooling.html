Cargo, crates and modules, testing and documentation: the everyday Rust workflow.

Cargo

cargo new shop                 # binary (src/main.rs); --lib for a library
cargo add serde --features derive; cargo add anyhow clap --features clap/derive
cargo check                    # fast type-check, no binary (use constantly)
cargo run -- --store 7         # arguments after --
cargo build --release          # optimised build in target/release/
cargo test; cargo clippy -- -D warnings; cargo fmt; cargo doc --open
[package]
name = "shop"
version = "0.1.0"
edition = "2024"

[dependencies]
serde = { version = "1", features = ["derive"] }

[dev-dependencies]

[profile.release]
lto = true                     # smaller and faster binaries

Modules and visibility

src/lib.rs          mod orders; mod stock; pub use orders::Order;
src/orders.rs       pub struct Order { pub id: u64, items: Vec<Item> }   ← items is private to the module
src/stock/mod.rs    (or src/stock.rs + src/stock/…) for nested modules
src/main.rs         use shop::Order;   (the binary uses the library crate by name)

Everything is private by default. pub exposes it; pub(crate) exposes it within this crate only. Paths: crate::orders::Order, super::helper, self::x.

Useful ecosystem
