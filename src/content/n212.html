Hybrid search runs both and merges the results. The standard merge is Reciprocal Rank Fusion, which needs no score calibration:

def rrf(result_lists, k=60):
    scores = {}
    for results in result_lists:                 # each is an ordered list of doc ids
        for rank, doc in enumerate(results):
            scores[doc] = scores.get(doc, 0) + 1 / (k + rank + 1)
    return sorted(scores, key=scores.get, reverse=True)

In Postgres: tsvector + pgvector in the same database, fused in SQL or in your app (chapter 103). Elasticsearch, OpenSearch, Qdrant and Weaviate have hybrid search built in. Hybrid search plus reranking is the strongest general-purpose retrieval setup.
