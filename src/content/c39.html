The universal language acquisition checklist and four-language roadmap: JavaScript, TypeScript, Python, and Go.

1. The Ten Questions for Any New Language

Whenever you learn any new programming language, fill out this 10-point architectural profile (keep it in your personal notes as your reference manual):

  1. Execution & Compilation: Is it compiled to native machine code (Go), compiled to bytecode and interpreted (Python, V8 JS), or transpiled/erased (TypeScript)?
  2. Typing Discipline: Is it statically typed or dynamically typed? Strongly typed or weakly typed? Does it use structural typing (TS, Go) or nominal typing (Java, C++)?
  3. Memory Management: Is it garbage-collected (JS, Python, Go), reference-counted with cycle detection (CPython), or manual/ownership-based (C, Rust)?
  4. Value vs Reference Semantics: What happens during assignment (b = a) or passing to a function? Does it copy values or copy references? What data structures are immutable?
  5. Error Handling: Does it throw exceptions (Python, JS), return explicit error values (Go), or use Result sum types (Rust, TS patterns)?
  6. Abstraction Paradigm: Does it use class-based inheritance (Python, modern JS), prototypes (JS engine), struct embedding and interfaces (Go), or functional composition?
  7. Collections & Data Structures: What are the standard sequence, map, and set types? What are their time complexity guarantees and iteration idioms?
  8. Strings & Unicode: How are strings encoded (UTF-8 in Go, UTF-16 in JS, Unicode code points in Python)? Is indexing $O(1)$ by byte or by character?
  9. Concurrency & Async I/O: Does it use an event loop (JavaScript), lightweight green threads / goroutines (Go), or async/await over thread pools (Python)? What synchronization primitives exist?
  10. Toolchain & Ecosystem: What is the standard package manager (npm/pnpm, uv, go mod), formatter (prettier, black/ruff, gofmt), linter, and test runner?
  11. Testing & Debugging: How are unit tests written? What debugger and profiler are standard?

3. The 5 Universal Programs to Build in Each Language

To verify that you truly know a language—rather than merely recognizing its syntax—implement these five projects from scratch without relying on AI code generation:

  1. Algorithmic Drill: Implement FizzBuzz, binary search, and an LRU cache with comprehensive automated unit tests.
  2. File & Data Processor: A CLI tool that reads a 50MB CSV/JSON log file, aggregates statistics into a hash map, and outputs a formatted report.
  3. HTTP Client & API Consumer: A CLI that fetches data from a REST API with exponential backoff retries, JSON validation, and error logging.
  4. Concurrent Job Worker: A worker pool processing tasks concurrently with cancellation, worker limits, and graceful shutdown.
  5. Production REST API: A microservice backed by PostgreSQL with connection pooling, migrations, health probes, and structured JSON logs.
