A tiny structure that answers "are these two things in the same group?" almost instantly, even while groups are merging.

every item points to a PARENT; the root of the chain is the group's representative parent: {a: a, b: a, c: b, d: d} a ← b ← c d find(c) → b → a (group "a") union(c, d): attach d's root under a's root → a ← b ← c, a ← d now c and d are connected
class UnionFind:
    def __init__(self, items):
        self.parent = {x: x for x in items}
        self.rank = {x: 0 for x in items}
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]   # path compression: point closer to the root
            x = self.parent[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False                          # already in the same group (for Kruskal: this edge would make a cycle)
        if self.rank[ra] < self.rank[rb]: ra, rb = rb, ra  # union by rank: attach the shorter tree under the taller
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]: self.rank[ra] += 1
        return True

With both optimisations, each operation costs almost O(1) (inverse Ackermann time, which is at most about 4 for any real input).

Uses: Kruskal's minimum spanning tree, "are these accounts linked?" (merging duplicate customers who share a phone or email), connected components as edges stream in, image segmentation, network connectivity.
