Images: the immutable, layered templates containers start from.

docker pull node:22-alpine
docker images                                   # local images and their sizes
docker history node:22-alpine                   # the layers, and what created each one
docker image inspect node:22-alpine | less      # env, entrypoint, architecture
docker run --rm node:22-alpine node -v          # a container = an image + a writable layer + a process
docker system df; docker image prune -a         # disk usage / clean unused images

Layers

Each Dockerfile instruction that changes the filesystem creates a layer (a diff). Layers are content-addressed (by SHA-256) and shared: ten images based on node:22-alpine store the base once. A container adds a thin writable layer on top, which is thrown away when the container is removed. That's why data must live in volumes (chapter 115).
