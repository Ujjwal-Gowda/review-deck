The graph algorithms that come up again and again in real systems: shortest paths, dependency ordering, and cheapest connections.

Dijkstra: shortest paths with non-negative weights

Idea: always settle the closest vertex not yet settled. A min-heap gives you "the closest" cheaply.

import heapq
def dijkstra(graph, src):
    dist = {src: 0}
    prev = {}
    heap = [(0, src)]
    while heap:
        d, v = heapq.heappop(heap)
        if d > dist.get(v, float("inf")): continue          # a stale entry: already found a shorter way
        for nxt, w in graph[v]:
            nd = d + w
            if nd < dist.get(nxt, float("inf")):
                dist[nxt] = nd; prev[nxt] = v
                heapq.heappush(heap, (nd, nxt))
    return dist, prev

def path_to(prev, target):                                  # rebuild the route by walking prev backwards
    out = [target]
    while out[-1] in prev: out.append(prev[out[-1]])
    return out[::-1]

Complexity: O((V + E) log V). It breaks with negative edge weights: use Bellman-Ford there. A* adds a heuristic (such as straight-line distance) to steer toward the goal, which is how maps and games route.

Topological sort: an order that respects dependencies

"pick before pack before deliver", or build steps, course prerequisites, package installs. It only works on a directed acyclic graph (DAG).

from collections import deque
def topo_sort(tasks, deps):                       # deps: (before, after)
    indeg = {t: 0 for t in tasks}; out = {t: [] for t in tasks}
    for a, b in deps: out[a].append(b); indeg[b] += 1
    q = deque(t for t in tasks if indeg[t] == 0)   # start with tasks that depend on nothing
    order = []
    while q:
        t = q.popleft(); order.append(t)
        for n in out[t]:
            indeg[n] -= 1
            if indeg[n] == 0: q.append(n)
    if len(order) != len(tasks): raise ValueError("cycle: no valid order")
    return order

Minimum spanning tree: connect everything as cheaply as possible

Example: laying cable between all stores for the lowest total length. Kruskal's algorithm: sort the edges by weight, and add each one unless it would form a cycle. Checking for cycles uses Union-Find.
