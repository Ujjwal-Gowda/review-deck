Last in, first out, like a stack of plates. Simple, and behind undo, function calls, parsers and backtracking.

push 1, push 2, push 3 pop → 3 pop → 2 │ 3 │ ← top │ │ │ │ │ 2 │ │ 2 │ ← top │ │ │ 1 │ │ 1 │ │ 1 │ ← top └───┘ └───┘ └───┘ Only the TOP is reachable. push, pop and peek are all O(1).
class Stack:
    def __init__(self): self._items = []            # a dynamic array: push/pop at the END are O(1)
    def push(self, x): self._items.append(x)
    def pop(self):
        if not self._items: raise IndexError("pop from empty stack")
        return self._items.pop()
    def peek(self): return self._items[-1]
    def __len__(self): return len(self._items)
# In practice: Python list, JS array push/pop, Go slice, Rust Vec, C array + top index

Where stacks show up

  • The call stack: each function call pushes a frame; each return pops one (Functions).
  • Undo / redo: push each edit; undo pops it onto a redo stack.
  • Browser back button, DFS (Graphs), and backtracking.
  • Matching brackets and evaluating expressions (compilers, calculators).

Worked example: evaluating Reverse Polish Notation

def eval_rpn(tokens):          # "3 4 + 2 *"  →  (3 + 4) * 2 = 14
    st = []
    for t in tokens:
        if t in "+-*/":
            b, a = st.pop(), st.pop()           # careful: the right operand comes off first
            st.append({"+": a + b, "-": a - b, "*": a * b, "/": a / b}[t])
        else:
            st.append(float(t))
    return st.pop()
tokens: 3 4 + 2 * stack: [3] [3,4] [7] [7,2] [14]

The monotonic stack pattern

"For each day, how many days until a warmer temperature?" Keep a stack of indices whose answer isn't known yet. When a warmer day arrives, pop and answer all the colder ones. It's O(n) overall, because each index is pushed and popped once.

def days_until_warmer(temps):
    ans, st = [0] * len(temps), []
    for i, t in enumerate(temps):
        while st and temps[st[-1]] < t:
            j = st.pop(); ans[j] = i - j
        st.append(i)
    return ans
