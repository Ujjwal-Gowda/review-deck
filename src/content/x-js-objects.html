Master JavaScript's object model: understand heap references, property descriptors, prototype chain delegation, the mechanics of the new operator, the four binding rules of this, and ES6 modern class syntax.

  • The new Operator Mechanics: Step through the exact four-step algorithm executed when instantiating a constructor function or class.
  • The 4 Rules of this: Predict the value of this across default, implicit, explicit, and new bindings, plus lexical arrow functions.
  • Modern Collections: Choose appropriately between Object, Map, Set, WeakMap, and WeakSet based on key types and garbage collection behavior.

2. Prerequisites & Mental Model

JavaScript does not have traditional class-based inheritance like Java or C++. Instead, it implements prototypal delegation:

  • Objects are Property Dictionaries: An object is a collection of key-value pairs stored in the V8 heap. Keys are either Strings or Symbols.
  • Delegation Links, Not Copying: When you access obj.foo, if foo is not found directly on obj, the engine does not fail. It delegates to obj's prototype object, then to that object's prototype, traversing the chain until it finds the property or reaches null.
  • Classes are Syntactic Sugar: The ES6 class keyword introduces a cleaner, safer syntax for declaring constructor functions and attaching methods to the prototype, but the underlying runtime behavior remains prototypal delegation.

3. Object Identity, References & Copying

Variables holding objects store a pointer (memory address in the heap). Reassigning does not clone the object; it copies the pointer.

const userA = { name: "Alice", settings: { theme: "dark" } };
const userB = userA; // Both point to the exact same memory address!

userB.name = "Bob";
console.log(userA.name); // "Bob" - Mutating through userB mutated userA!
console.log(userA === userB); // true (Identical reference)

// 1. Shallow Copy (Spread operator or Object.assign)
const shallowCopy = { ...userA };
shallowCopy.name = "Charlie";
console.log(userA.name); // "Bob" (Top-level primitive is cloned)
shallowCopy.settings.theme = "light";
console.log(userA.settings.theme); // "light" (Nested objects are STILL shared references!)

// 2. Deep Copy (Native structuredClone)
const deepCopy = structuredClone(userA);
deepCopy.settings.theme = "contrast";
console.log(userA.settings.theme); // "light" (Completely independent heap tree!)

4. Property Descriptors & Immutability Levels

Every property in a JavaScript object is backed by a Property Descriptor containing four flags:

Descriptor Attribute Default (Literal) Runtime Meaning
value Assigned value The actual data value associated with the property.
writable true If false, the property value cannot be changed via assignment.
enumerable true If false, the property is hidden from for...in loops and Object.keys().
configurable true If false, the property cannot be deleted and descriptor flags cannot be modified. 
const account = {};
Object.defineProperty(account, "id", {
  value: "ACC-9921",
  writable: false,      // Cannot be changed
  enumerable: true,     // Visible in Object.keys()
  configurable: false   // Cannot be deleted or reconfigured
});

account.id = "ACC-0000"; // Silently fails in sloppy mode; throws TypeError in strict mode
console.log(account.id); // "ACC-9921"

Comparing Immutability Helpers:

  • Object.preventExtensions(obj): Prevents adding new properties. Existing properties can still be modified or deleted.
  • Object.seal(obj): Prevents adding or removing properties. Marks all existing properties as configurable: false. Existing writable properties can still be modified.
  • Object.freeze(obj): The ultimate shallow freeze. Prevents adding, removing, or modifying properties (writable: false, configurable: false). Note: nested objects remain mutable unless recursively frozen!

5. Prototypes & The Prototype Chain

Every JavaScript object has an internal hidden link, [[Prototype]] (accessible via Object.getPrototypeOf() or legacy __proto__).

const animal = {
  makeSound() {
    return `${this.name} makes a sound.`;
  }
};

// Create dog with animal as its [[Prototype]]
const dog = Object.create(animal);
dog.name = "Rover";

console.log(dog.makeSound()); // "Rover makes a sound."
console.log(dog.hasOwnProperty("name"));      // true  (own property)
console.log(dog.hasOwnProperty("makeSound")); // false (delegated to animal prototype!)

// Prototype lookup chain:
// dog -> animal -> Object.prototype -> null
console.log(Object.getPrototypeOf(dog) === animal); // true
console.log(Object.getPrototypeOf(animal) === Object.prototype); // true
console.log(Object.getPrototypeOf(Object.prototype)); // null (end of chain)

6. The new Operator: Step-by-Step Mechanics

When you invoke a function with new Person("Alice"), the JavaScript engine executes these four steps in order:

  1. Allocates a new plain JavaScript object: const obj = {};
  2. Links the prototype: Sets obj.__proto__ = Person.prototype;
  3. Binds this and runs constructor: Invokes Person.call(obj, "Alice"). Inside the constructor, this points to the new object.
  4. Returns the instance: If the constructor returns an object explicitly, that object is returned; otherwise, returns the freshly created obj.
// Manual reconstruction of the 'new' operator:
function customNew(Constructor, ...args) {
  // 1 & 2: Create object linked to constructor's prototype
  const instance = Object.create(Constructor.prototype);
  // 3: Execute constructor with this bound to instance
  const result = Constructor.apply(instance, args);
  // 4: Return object if constructor returned one, else instance
  return (typeof result === "object" && result !== null) ? result : instance;
}

7. The Four Rules of this Binding

The value of this is determined at call time (call-site), not at declaration time, following these four rules ranked in order of priority:

  1. new Binding (Highest Priority): If called with new, this refers to the newly created instance.
  2. Explicit Binding: If called with .call(), .apply(), or .bind(), this is explicitly set to the provided argument.
  3. Implicit Binding: If called as a method of an object (e.g. user.greet()), this is the object immediately preceding the dot.
  4. Default Binding (Lowest Priority): Standalone function invocation (e.g. greet()). In strict mode, this is undefined. In sloppy mode, this falls back to window or globalThis.
Exception: Arrow Functions: Arrow functions do not have their own this binding! They capture this lexically from their enclosing scope at the moment they are created, and cannot be rebound using call, apply, or bind. 
const logger = {
  name: "ServiceLogger",
  logNormal: function() {
    console.log(this.name);
  },
  logArrow: () => {
    console.log(this.name); // Lexical this (enclosing scope: global/undefined)
  }
};

logger.logNormal(); // "ServiceLogger" (Implicit binding: called on logger)
logger.logArrow();  // undefined (Arrow function ignores logger!)

const detached = logger.logNormal;
detached(); // undefined (Default binding in strict mode: lost context!)

// Fixing lost context with bind:
const boundLogger = logger.logNormal.bind(logger);
boundLogger(); // "ServiceLogger"

8. Modern ES6+ Classes & Encapsulation

Modern JavaScript classes provide clean syntax for constructors, prototype methods, static utilities, and true hard private fields (prefixed with #):

class BankAccount {
  // True private fields (enforced by V8 engine at runtime)
  #balance = 0;
  #accountNumber;

  static #totalAccounts = 0;

  constructor(accountNumber, initialDeposit = 0) {
    this.#accountNumber = accountNumber;
    this.#balance = initialDeposit;
    BankAccount.#totalAccounts++;
  }

  deposit(amount) {
    if (amount <= 0) throw new RangeError("Deposit amount must be positive");
    this.#balance += amount;
    return this.#balance;
  }

  // Getter property
  get balance() {
    return this.#balance;
  }

  // Static method
  static getTotalAccounts() {
    return BankAccount.#totalAccounts;
  }
}

const account = new BankAccount("ACC-100", 500);
account.deposit(250);
console.log(account.balance); // 750
// console.log(account.#balance); // SyntaxError: Private field '#balance' must be declared in an enclosing class

9. Modern Collections: Map, Set, WeakMap, WeakSet

Do not use plain Objects as general-purpose key-value maps. Use the modern collections:

Collection Key Types Key Features & Differences from Plain Object
Map Any value (primitives, objects, functions) Guaranteed insertion order; accurate .size property; no prototype pollution risks; faster for frequent insertions and deletions.
Set Any unique value Stores unique values; provides O(1) membership testing (.has()); automatically eliminates duplicates.
WeakMap Objects only Keys are held weakly. If no other references to a key object exist, the entry is automatically garbage-collected. Prevents memory leaks in metadata caching.
WeakSet Objects only Objects held weakly; cannot be iterated; ideal for tagging objects (e.g. marking processed DOM nodes). 
// Preventing Memory Leaks with WeakMap:
const metadataCache = new WeakMap();

function processUser(user) {
  // Cache computation without preventing garbage collection of user
  if (!metadataCache.has(user)) {
    metadataCache.set(user, { processedAt: Date.now() });
  }
  return metadataCache.get(user);
}

let activeUser = { id: 42 };
processUser(activeUser);

// When activeUser is discarded:
activeUser = null; 
// The metadataCache entry is automatically cleaned up by V8 GC!

10. Common Gotchas & Anti-Patterns

  • Passing Object Methods as Unbound Callbacks: e.g. setTimeout(obj.method, 100) or button.addEventListener("click", obj.handleClick) strips implicit binding, causing this to be undefined. Fix: () => obj.handleClick() or .bind(obj).
  • Assuming Shallow Copy is Deep: { ...obj } only clones top-level keys. Mutating nested arrays or objects alters the original source.
  • Iterating Plain Objects with for...in without Guards: for...in walks the entire prototype chain. Always prefer Object.keys(), Object.values(), or Object.entries().
  • Modifying Object.prototype: Monkey-patching global prototypes pollutes every object in the process and creates catastrophic security vulnerabilities (Prototype Pollution).
