From text file to electrons: what "running code" really means, how an application boots up, and mastering Python, JavaScript, TypeScript, and Go in depth from day one.

1. The Machine: Hardware & CPU Cycle

A computer is, at its core, a CPU that repeatedly does one thing: fetch an instruction from memory, decode it, execute it, and move on to the next. Instructions are tiny: "add these two numbers", "copy this value from memory address 1000 into a register", "if the last result was zero, jump to instruction 57". Billions per second.

┌──────────────── CPU ────────────────┐ ┌──────── RAM (memory) ────────┐ │ registers: tiny, ultra-fast slots │ ◄────► │ addr 0000: instruction/data │ │ ALU: does arithmetic & logic │ bus │ addr 0001: … │ │ control unit: fetch → decode → run │ │ … billions of numbered bytes │ └─────────────────────────────────────┘ └──────────────────────────────┘ ▲ ▲ └── disk / network / keyboard / screen (I/O) ┘ (much slower)

Memory (RAM) is a giant array of bytes, each with a numeric address. Everything (your numbers, your text, the program itself) is bytes at addresses. Disk keeps data after power-off but is thousands of times slower than RAM. That speed gap drives many design decisions you'll see later.

2. What Does an Application Even Do When It Starts?

When you type a command in your terminal like python3 link.py or npm run dev or go run main.go, what actually happens under the hood before a single line of your logic prints to the screen?

[Terminal Shell: bash / zsh] │ 1. fork() + execve("/usr/bin/python3", ["python3", "link.py"]) ▼ [OS Kernel: Process Setup] ├── Maps private Virtual Memory pages (Code, Data, Heap, Stack) ├── Attaches Standard I/O Streams: stdin (fd 0), stdout (fd 1), stderr (fd 2) └── Transfers CPU control to CPython's entry point │ ▼ [CPython Runtime Initialization: Py_Initialize()] ├── Inits internal types (int, str, dict) & builtins (print, len, open) ├── Sets sys.path (where imports look for modules) & initializes GIL └── Allocates the Main Thread State │ ▼ [Source Compilation Phase] ├── Reads "link.py" file bytes from disk into memory ├── Tokenizer: text ──► Token Stream ├── Parser: Token Stream ──► Abstract Syntax Tree (AST) └── Bytecode Compiler: AST ──► Code Object (opcodes: LOAD_NAME, CALL, etc.) │ ▼ [The Evaluation Loop: ceval.c] └── Executes bytecode instructions on the stack sequentially until exit(0)

Tracing a Real Script: How link.py Boots in this App

In this repository, look at the helper script link.py:

# link.py
import os, re
p = 'src/curriculum.ts'; s = open(p).read()
a = s.index('const RAW = `') + len('const RAW = `'); b = s.index('`;', a)
out, n = [], 0
for line in s[a:b].split('\n'):
    if line and not line.startswith('#'):
        title, lvl, content, topics = line.split('|', 3)
        key = f'n{n:02d}'
        if not content and os.path.exists(f'src/content/{key}.html'):
            line = f'{title}|{lvl}|{key}|{topics}'
        n += 1
    out.append(line)
open(p, 'w').write(s[:a] + '\n'.join(out) + s[b:])

When Python executes this:

  1. import os, re: The VM pauses the main script to check sys.modules. If not already imported, it locates os.py in Python's standard library, parses it, executes its code object, and binds the name os in your script's global namespace dict (globals()).
  2. p = 'src/curriculum.ts'; s = open(p).read(): Python creates a string object on the heap for 'src/curriculum.ts'. The open() builtin triggers an OS system call (openat). The kernel returns a file descriptor integer. .read() makes a read syscall copying raw bytes from disk through OS buffer caches into a Python Unicode string object on the heap.
  3. String Searching & Slicing: Python searches the heap byte array for the substring 'const RAW = `' and finds its offset. Python strings are immutable: slicing s[a:b] creates a new string on the heap containing just the curriculum table.
  4. Loop Iteration: .split('\n') builds a Python list of string references. The VM pushes stack frames, extracts fields with .split('|', 3), checks if the HTML file exists on disk via os.path.exists, and appends to the out list.
  5. Saving & Termination: open(p, 'w').write(...) opens the file with write permissions, flushes the new string buffer back to disk via the kernel, collects remaining heap garbage, releases file descriptors, and exits with code 0.

3. Language 1: Python In-Depth

Python is an expressive, dynamically typed language where readability and developer speed come first.

Syntax & Indentation Rules

Python uses indentation (typically 4 spaces, never tabs) instead of curly braces {} to define blocks of code:

# 1. Variables and Dynamic Typing
# You do not specify types when declaring variables. Types belong to the value, not the name.
age = 25              # int (unbounded size in Python 3!)
price = 19.99         # float (64-bit IEEE 754)
greeting = "Hello"    # str (immutable unicode)
is_active = True      # bool (True or False, capitalized!)
empty_val = None      # None represents absence of value (like null in other languages)

# Optional Type Annotations (checked by tools like pyright or mypy, ignored at runtime):
username: str = "alex"
score: int = 100

Collections & Data Structures

# List: Ordered, mutable sequence (like an array)
fruits = ["apple", "banana", "cherry"]
fruits.append("date")
first = fruits[0]      # "apple"
subset = fruits[1:3]   # ["banana", "cherry"] (half-open range [1, 3))

# Dictionary: Hash map of key-value pairs (fast O(1) lookup)
user = {
    "id": 1,
    "name": "Alice",
    "role": "admin"
}
user["email"] = "alice@example.com"
name = user.get("name", "Unknown")  # Safe lookup with default fallback

# Tuple: Ordered, IMMUTABLE sequence (cannot be changed after creation)
point = (10, 20)
# point[0] = 5  # TypeError: 'tuple' object does not support item assignment

# Set: Unordered collection of UNIQUE elements
unique_tags = {"python", "go", "python"}  # {"python", "go"}

Control Flow & Loops

# Conditionals
if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teenager")
else:
    print("Child")

# For loop with range
for i in range(3):  # 0, 1, 2
    print(f"Index {i}")

# For loop iterating directly over items
for item in fruits:
    print(item)

# Enumerate: Get both index and item simultaneously
for idx, fruit in enumerate(fruits):
    print(f"{idx}: {fruit}")

# List Comprehension: Idiomatic, concise list transformation
doubled = [x * 2 for x in [1, 2, 3, 4] if x % 2 == 0]  # [4, 8]

Functions, Closures, and Error Handling

# Functions with defaults and type hints
def calculate_tax(amount: float, rate: float = 0.05) -> float:
    """Compute tax on a given amount."""
    if amount < 0:
        raise ValueError("Amount cannot be negative")
    return amount * rate

# Error Handling (try / except / finally)
try:
    total = calculate_tax(-50.0)
except ValueError as err:
    print(f"Handled expected error: {err}")
finally:
    print("Execution complete (runs no matter what)")

4. Language 2: JavaScript (ESM) In-Depth

JavaScript is the native language of every web browser and a dominant backend language via Node.js.

Variables: const vs let (Never use var)

// const: Cannot be reassigned (use by default)
const maxAttempts = 3;
// maxAttempts = 5; // TypeError: Assignment to constant variable

// let: Reassignable variable (scoped to the surrounding { } block)
let currentScore = 0;
currentScore += 10;

// Primitive types: number (double float), string, boolean, null, undefined, bigint, symbol
const pi = 3.14159;
const userGreeting = `Current score is ${currentScore}`; // Template literal (backticks)
const isOnline = true;
const missing = null;       // Intentional absence of value
let unassigned;             // undefined: variable declared but has no value yet

Objects and Arrays

// Objects: Collections of key-value pairs
const person = {
  id: 42,
  name: "Bob",
  greet() {
    return `Hi, I am ${this.name}`;
  }
};

// Arrays & High-Order Array Methods
const numbers = [1, 2, 3, 4, 5];
numbers.push(6);

// map: transform every element
const doubled = numbers.map(n => n * 2);

// filter: keep elements matching condition
const evens = numbers.filter(n => n % 2 === 0);

// reduce: accumulate items into a single result
const sum = numbers.reduce((acc, curr) => acc + curr, 0);

Functions and Arrow Functions

// Traditional function declaration
function add(a, b = 0) {
  return a + b;
}

// Arrow function (concise, captures surrounding 'this')
const multiply = (a, b) => a * b;

// Async / Await & Promises (Non-blocking I/O)
async function fetchUser(userId) {
  try {
    const response = await fetch(`https://api.example.com/users/${userId}`);
    if (!response.ok) throw new Error(`HTTP Error: ${response.status}`);
    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Failed to fetch user:", error.message);
    return null;
  }
}

5. Language 3: TypeScript In-Depth

TypeScript is JavaScript with syntax for types. Every valid JavaScript program is valid TypeScript. The TypeScript compiler (tsc) verifies types at build-time and erases them completely, outputting pure JavaScript.

Type Annotations and Interfaces

// Basic Type Annotations
const appName: string = "Foundations";
let activeUsers: number = 1420;
const isProduction: boolean = false;

// Interfaces: Define the exact shape an object must satisfy
interface Product {
  id: string;
  title: string;
  price: number;
  tags?: string[]; // Optional property (can be undefined)
  readonly createdAt: Date; // Cannot be modified after instantiation
}

const book: Product = {
  id: "prod_01",
  title: "Engineering Foundations",
  price: 29.99,
  createdAt: new Date()
};

Union Types and Type Narrowing

// Union Types: A value can be one of several types
type ResultStatus = "idle" | "loading" | "success" | "error";

interface ApiResponse {
  status: ResultStatus;
  data?: string;
  error?: string;
}

// Type Narrowing with typeof / guard clauses
function formatValue(val: string | number): string {
  if (typeof val === "number") {
    return val.toFixed(2); // TypeScript knows val is number here!
  }
  return val.trim().toUpperCase(); // TypeScript knows val is string here!
}

Generics: Writing Reusable, Type-Safe Code

// A generic function that works with any type T while preserving its type
function wrapInArray(item: T): T[] {
  return [item];
}

const numArray = wrapInArray(42);       // Inferred as number[]
const strArray = wrapInArray("hello");  // Inferred as string[]

6. Language 4: Go In-Depth

Go (Golang) is a statically typed, compiled language created by Google for scalable backend systems, cloud platforms, and developer tooling. It prioritizes simplicity, fast compilation, and lightweight concurrency.

Program Structure, Variables & Zero Values

package main

import (
    "fmt"
    "errors"
)

func main() {
    // 1. Explicit variable declaration
    var port int = 8080

    // 2. Short declaration operator ':=' (inferred inside functions)
    host := "localhost"
    isActive := true

    // 3. ZERO VALUES: In Go, variables are NEVER uninitialized!
    var count int        // 0
    var message string   // ""
    var isDone bool      // false
    var ptr *int         // nil

    fmt.Printf("Server starting on %s:%d (active: %t, count: %d)\n", host, port, isActive, count)
}

Slices and Maps

// Slices: Dynamically-sized views into underlying arrays
nums := []int{10, 20, 30}
nums = append(nums, 40) // append allocates more capacity if needed

fmt.Println("Length:", len(nums)) // 4

// Maps: Hash tables (key-value)
userRoles := make(map[string]string)
userRoles["alice"] = "admin"
userRoles["bob"] = "viewer"

// Reading with the "comma-ok" idiom:
role, exists := userRoles["charlie"]
if !exists {
    fmt.Println("User not found in map")
} else {
    fmt.Println("Role:", role)
}

Structs, Methods & Explicit Errors (No Exceptions)

// Struct: Defining custom data models
type Account struct {
    Owner   string
    Balance float64
}

// Method attached to Account struct
func (a *Account) Deposit(amount float64) error {
    if amount <= 0 {
        return errors.New("deposit amount must be positive")
    }
    a.Balance += amount
    return nil // nil indicates no error
}

// Calling functions with multiple return values
func Divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("cannot divide by zero")
    }
    return a / b, nil
}

Concurrency: Goroutines & Channels

// Concurrency is built into Go's core keywords:
func fetchScore(userId int, ch chan int) {
    // runs concurrently
    ch <- userId * 10 // send result into channel
}

func testConcurrency() {
    ch := make(chan int)
    go fetchScore(5, ch) // 'go' launches a concurrent Goroutine (~2KB memory)
    result := <-ch       // wait to receive from channel
    fmt.Println("Received:", result)
}

7. The Rosetta Example: One Real Task in All 4 Languages

To feel comfortable writing each language, compare how each solves the identical task: Given a list of numbers, filter out odd numbers, double the even numbers, compute the total sum, and handle potential errors safely.

Python

def process_numbers(numbers: list[int]) -> int:
    if not numbers:
        raise ValueError("List cannot be empty")
    evens = [n * 2 for n in numbers if n % 2 == 0]
    return sum(evens)

try:
    result = process_numbers([1, 2, 3, 4, 5, 6])
    print(f"Total: {result}") # Total: 24 (4 + 8 + 12)
except ValueError as e:
    print(f"Error: {e}")

JavaScript

function processNumbers(numbers) {
  if (!numbers || numbers.length === 0) {
    throw new Error("List cannot be empty");
  }
  return numbers
    .filter(n => n % 2 === 0)
    .map(n => n * 2)
    .reduce((sum, n) => sum + n, 0);
}

try {
  const result = processNumbers([1, 2, 3, 4, 5, 6]);
  console.log(`Total: ${result}`); // Total: 24
} catch (err) {
  console.error(`Error: ${err.message}`);
}

TypeScript

function processNumbers(numbers: number[]): number {
  if (numbers.length === 0) {
    throw new Error("List cannot be empty");
  }
  return numbers
    .filter((n: number): boolean => n % 2 === 0)
    .map((n: number): number => n * 2)
    .reduce((sum: number, n: number): number => sum + n, 0);
}

try {
  const result: number = processNumbers([1, 2, 3, 4, 5, 6]);
  console.log(`Total: ${result}`); // Total: 24
} catch (err) {
  const msg = err instanceof Error ? err.message : String(err);
  console.error(`Error: ${msg}`);
}

Go

package main

import (
    "errors"
    "fmt"
)

func ProcessNumbers(numbers []int) (int, error) {
    if len(numbers) == 0 {
        return 0, errors.New("list cannot be empty")
    }
    total := 0
    for _, n := range numbers {
        if n%2 == 0 {
            total += n * 2
        }
    }
    return total, nil
}

func main() {
    result, err := ProcessNumbers([]int{1, 2, 3, 4, 5, 6})
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    fmt.Printf("Total: %d\n", result) // Total: 24
}

8. Programs as Processes & Standard Streams

When you run any program, the operating system creates a process: a running instance with its own private virtual memory space, a program counter (which instruction executes next), open file descriptors, and three standard streams:

  • stdin (standard input, fd 0): where input comes from (keyboard, or a pipe)
  • stdout (standard output, fd 1): normal output
  • stderr (standard error, fd 2): error messages, kept separate so they aren't mixed into data
python3 hello.py > out.txt        # stdout goes to a file
python3 broken.py 2> errors.txt   # stderr goes to a file
echo "5" | python3 double.py      # stdout of echo becomes stdin of python

1.3 think Look at the bytecode Python makes for a function. What do you notice?
import dis
def add(a, b):
    return a + b
dis.dis(add)

You'll see instructions like LOAD_FAST a, LOAD_FAST b, BINARY_OP +, RETURN_VALUE. It's a stack machine: push two values, add them, return the top. This is the bytecode layer the CPython VM loop executes.

1.4 intermediate In Go, create a slice, append 5 items to it, and print its length and capacity at each step using len(s) and cap(s).
package main
import "fmt"
func main() {
    var s []int
    for i := 1; i <= 5; i++ {
        s = append(s, i)
        fmt.Printf("Item %d: len=%d cap=%d\n", i, len(s), cap(s))
    }
}

Notice how capacity doubles (0 → 1 → 2 → 4 → 8) to maintain $O(1)$ amortized append performance!
