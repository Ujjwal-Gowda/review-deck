Designing user interfaces around non-deterministic AI: smart autocompletes, progressive enhancement, error states, and confidence indicators.

UI Rules for AI Products

  • Always permit user editing: Treat AI outputs as drafts or suggestions, never unalterable final states.
  • Indicate provenance: Highlight AI-generated fields with a subtle visual cue so the user knows to verify.
  • Provide single-click undo / reset: If an AI autocomplete overwrites form inputs, make reverting instantaneous.
  • Graceful degradation: When the AI service times out or errors, fall back to standard manual inputs without breaking form submission.
