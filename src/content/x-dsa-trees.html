Hierarchies: folders, HTML, org charts, JSON, syntax trees. The vocabulary, and the four ways to walk a tree.

┌─────────── root (no parent) ▼ (A) depth 0 / \ (B) (C) depth 1 B and C are CHILDREN of A; siblings of each other / \ \ (D) (E) (F) depth 2 D, E, F are LEAVES (no children) height of the tree = 2 (longest root-to-leaf path, counted in edges) a SUBTREE = any node plus all of its descendants (B, D, E is the subtree rooted at B)

A binary tree is one where every node has at most two children, left and right.

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

root = TreeNode("A", TreeNode("B", TreeNode("D"), TreeNode("E")), TreeNode("C", None, TreeNode("F")))

def preorder(n):
    if n is None: return []
    return [n.val] + preorder(n.left) + preorder(n.right)

def inorder(n):
    if n is None: return []
    return inorder(n.left) + [n.val] + inorder(n.right)

from collections import deque
def level_order(root):
    out, q = [], deque([root] if root else [])
    while q:
        n = q.popleft(); out.append(n.val)
        if n.left: q.append(n.left)
        if n.right: q.append(n.right)
    return out

Thinking recursively about trees

Almost every tree question has the same shape: "answer for this node = combine(answer for left, answer for right)". Trust the recursion (Recursion):

def height(n):  return -1 if n is None else 1 + max(height(n.left), height(n.right))
def count(n):   return 0 if n is None else 1 + count(n.left) + count(n.right)
def mirror(n):
    if n: n.left, n.right = mirror(n.right), mirror(n.left)
    return n
