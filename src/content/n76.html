Loading

  • Ship less JS: check the bundle (npx vite-bundle-visualizer). The build warning about a 555 KB chunk on this site is exactly this. Heavy libraries (date, chart, editor) often dominate.
  • Code-split: const Admin = lazy(() => import("./Admin")) per route or feature.
  • Images: WebP/AVIF, the right size (srcset), loading="lazy" below the fold, and fetchpriority="high" for the hero image.
  • Caching: hashed filenames plus Cache-Control: immutable, so repeat visits cost nothing.
  • Fonts: font-display: swap, preload the one critical font, subset them.

Rendering (React)

  • Profile first with React DevTools Profiler: which components re-render, and why.
  • Keep state low in the tree so updates re-render less; memoise expensive subtrees (memo) only where the profiler shows it matters.
  • Virtualise long lists (TanStack Virtual). Rendering 5,000 order rows kills INP.
  • useDeferredValue / startTransition keep typing responsive during heavy filtering.

Measure on a mid-range phone with network throttling (DevTools → Performance, "Slow 4G", 4× CPU slowdown). Your laptop hides the problems.
