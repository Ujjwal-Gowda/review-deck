Autoscaling basics

  • Scale on the signal that reflects load: CPU for compute-bound work, queue depth for workers, concurrency or latency for APIs.
  • Instances must be stateless and start fast; add health checks so the load balancer only sends traffic to ready instances.
  • Set minimum and maximum limits (the max protects your bill and your database); scale out fast and in slowly.
  • Spot/preemptible instances cost 60–90% less but can be taken back at short notice: fine for batch jobs, renders and CI.

Practice

128.1 think The worker processing renders needs 4 GB of RAM for 10 minutes, twice a day. Which compute option fits best?

A serverless container job (Cloud Run jobs, ECS Fargate task) or a spot VM started by a scheduler: you pay only while it runs. Lambda's limits (memory, 15-minute timeout) make it a poor fit.
