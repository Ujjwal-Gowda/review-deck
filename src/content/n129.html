s3 = boto3.client("s3")
s3.upload_file("invoice-42.pdf", "freshon-invoices", "2026/09/invoice-42.pdf")
url = s3.generate_presigned_url("get_object", Params={"Bucket": "freshon-invoices", "Key": "2026/09/invoice-42.pdf"},
                                ExpiresIn=3600)      # a time-limited link: the bucket stays private
# presigned PUT URLs let browsers upload directly to S3, so big files never pass through your server

Object storage essentials

  • Keep buckets private (public-bucket leaks are a classic breach); serve files via presigned URLs or a CDN with origin access control.
  • Storage classes and lifecycle rules: move old objects to cheaper tiers, and expire temporary files automatically.
  • Versioning protects against accidental deletes and ransomware.
  • Egress costs: serving lots of video from S3 directly is expensive. Use a CDN, or providers with free egress (Cloudflare R2).
  • Objects are immutable: "editing" one means writing a new object.
Security lens · Object storage

Public buckets are among the most common data breaches. Block public access account-wide, and serve private files through short-lived presigned URLs.

Practice

129.1 basic Upload a file to S3 (or R2) with the CLI, generate a presigned URL valid for 10 minutes, and confirm it expires.

aws s3 cp f s3://b/f, then aws s3 presign s3://b/f --expires-in 600. After 10 minutes the URL returns 403 AccessDenied (Request has expired).
