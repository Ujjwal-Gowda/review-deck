How software gets onto a Debian system, and how to keep that tidy.

sudo apt update                 # refresh package lists from the repositories
apt search ripgrep; apt show ripgrep
sudo apt install ripgrep        # resolves and installs dependencies
sudo apt upgrade                # upgrade everything installed
sudo apt remove --purge pkg && sudo apt autoremove   # remove it, its config, and orphaned dependencies
dpkg -L ripgrep                 # which files did this package install?
dpkg -S /usr/bin/rg             # which package owns this file?
apt policy firefox              # installed vs candidate version, and which repo it comes from
SourceTrade-off
apt (Debian repos)stable, tested, auto-updated; often older versions
Extra apt repos (/etc/apt/sources.list.d)newer vendor builds (Docker, Node); you trust that vendor's signing key
Flatpak / Snapsandboxed and self-contained, up to date; bigger, duplicate libraries
Language managers (pip/uv, npm, cargo, go install)install into your user folder, no root needed (e.g. npm i -g --prefix ~/.local)
AppImage / tarball in /optone file, no install; no automatic updates

Never sudo pip install or sudo npm i -g into system directories: it fights with apt-managed files. Use user installs or per-project environments.
