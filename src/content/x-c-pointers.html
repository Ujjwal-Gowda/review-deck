Pointers explained slowly: what they are, the two operators, pointer arithmetic, arrays, and function pointers.

A pointer is an address

int qty = 42; memory: address 0x1000 → [ 42 ] (qty) int *p = &qty; address 0x2000 → [0x1000] (p holds the ADDRESS of qty) &qty "address of qty" → 0x1000 *p "the value at address p" → 42 *p = 7 writes through the pointer → qty is now 7
int qty = 42;
int *p = &qty;
printf("%d %p %d\n", qty, (void *)p, *p);   /* 42 0x7ffd… 42 */
*p += 1;                                     /* qty == 43 */
int **pp = &p;  **pp = 0;                    /* pointer to pointer: qty == 0 */
int *nothing = NULL;                          /* points nowhere: dereferencing it crashes (segfault) */

Why pointers exist

  1. Let functions modify the caller's data (C passes copies): swap(&a, &b).
  2. Avoid copying big structs: pass const Order * instead of Order.
  3. Dynamic memory: malloc returns a pointer (Dynamic Memory).
  4. Linked structures: lists, trees and graphs (Linked Lists).

Arrays and pointer arithmetic

int prices[4] = {40, 60, 120, 260};
int *q = prices;              /* the array name "decays" to &prices[0] */
q[2] == *(q + 2)              /* true: indexing IS pointer arithmetic */
q + 1                         /* advances by sizeof(int) = 4 bytes, not 1 */
for (int *it = prices; it < prices + 4; it++) printf("%d\n", *it);

void print_all(const int *a, size_t n);   /* a function can't know an array's length: always pass n */
sizeof prices                 /* 16 here, but sizeof(a) inside print_all is 8: just a pointer! */

const and pointers

const char *name     /* can't change the chars through name (read-only view): use for inputs */
char *const buf      /* can't point buf elsewhere, but the chars can change */
const char *const k  /* neither */

Function pointers: C's callbacks

int by_qty_desc(const void *a, const void *b) {
    const Item *x = a, *y = b;
    return (y->qty > x->qty) - (y->qty < x->qty);   /* avoids overflow from subtraction */
}
qsort(items, n, sizeof items[0], by_qty_desc);

typedef void (*Handler)(const char *msg);           /* name the type for readability */
Handler handlers[] = { log_msg, send_sms };
for (size_t i = 0; i < 2; i++) handlers[i]("stock low");

Common pointer bugs

  • Dereferencing NULL or uninitialised pointers: a segfault, or silent garbage.
  • Dangling pointers: returning the address of a local variable (it dies when the function returns), or using memory after free.
  • Out-of-bounds arithmetic: reading past the end silently corrupts data.

AddressSanitizer (-fsanitize=address) finds most of these instantly, so always use it while learning.

Practice

0.1 basic Write void minmax(const int *a, size_t n, int *min, int *max), void reverse(int *a, size_t n) using two pointers, and int *find(int *a, size_t n, int x) that returns a pointer or NULL.

Reverse: for (int *l = a, *r = a + n - 1; l < r; l++, r--) { int t = *l; *l = *r; *r = t; }, guarding n == 0 first. find: loop, if (a[i] == x) return &a[i];, then return NULL;. The caller checks for NULL.
