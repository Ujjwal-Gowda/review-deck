Formatting

Py  f"{name} owes ₹{amt:,.2f}"
TS  `${name} owes ₹${amt.toFixed(2)}`
Go  fmt.Sprintf("%s owes ₹%.2f", name, amt)
Rs  format!("{name} owes ₹{amt:.2}")
C   snprintf(buf, sizeof buf, "%s owes %.2f", name, amt)

Split / join / trim

Py  s.split(","); ",".join(xs); s.strip()
TS  s.split(","); xs.join(","); s.trim()
Go  strings.Split(s, ","); strings.Join(xs, ","); strings.TrimSpace(s)
Rs  s.split(',').collect::<Vec<_>>(); xs.join(","); s.trim()
C   strtok (destructive!) / strsep; manual joins

Contains / find / replace

Py  "sh" in s; s.find("x"); s.replace("a","b")
TS  s.includes("sh"); s.indexOf("x"); s.replaceAll("a","b")
Go  strings.Contains(s,"sh"); strings.Index(s,"x"); strings.ReplaceAll(s,"a","b")
Rs  s.contains("sh"); s.find('x'); s.replace("a","b")
C   strstr(s, "sh")  /* returns a pointer or NULL */

Build strings in a loop

Py  parts.append(x) … "".join(parts)
TS  parts.push(x) … parts.join("")
Go  var b strings.Builder; b.WriteString(x); b.String()
Rs  let mut s = String::new(); s.push_str(x);
C   size-tracked buffer + snprintf / memcpy

Parse numbers

Py  int(s)          # ValueError on bad input
TS  Number(s)       // NaN on bad input (check it!)
Go  strconv.Atoi(s) // (n, err)
Rs  s.parse::<i64>() // Result
C   strtol(s, &end, 10) // check end and errno

Iterate characters

Py  for ch in s:          # code points
TS  for (const ch of s)   // code points (s[i] = UTF-16 unit)
Go  for i, r := range s   // runes; s[i] = a byte
Rs  for ch in s.chars()   // chars; s.bytes() for bytes
C   for (char *p = s; *p; p++)  /* bytes */

Traps when switching

  • Indexing: s[0] is a code point in Python, a UTF-16 unit in JS, a byte in Go, not allowed in Rust (use .chars().nth(0) or byte slicing on a char boundary), and a byte in C.
  • Concatenating in a loop is O(n²) in every language: use the builder.
  • C strings: every copy must fit its destination plus the NUL. Use snprintf, never strcpy/strcat/gets.
  • Rust String vs &str: take &str as a parameter (it accepts both); return String when you create new text.

Practice

0.1 basic Reverse the string "héllo 😀" correctly in all five languages. Where does the naive approach break?

Python: s[::-1] works for these characters (combining marks would still break). JS: [...s].reverse().join(""), because split("") breaks the emoji's surrogate pair. Go: convert to []rune and reverse. Rust: s.chars().rev().collect::<String>(). C: byte reversal corrupts multi-byte UTF-8, so you'd need to decode first. Full grapheme correctness needs a library in every language.
