Quorums

With N replicas, write to W and read from R. If W + R > N, every read overlaps with the latest write (e.g. N=3, W=2, R=2). Lower W or R buys speed and availability at the cost of consistency.

Practical techniques

  • Route a user's reads to the leader for a few seconds after they write (read-your-writes on top of async replicas).
  • Pin a session to one replica (monotonic reads).
  • Conflict resolution for concurrent writes: last-writer-wins (simple, but loses data), version vectors, or CRDTs (data types that merge automatically: counters, sets, collaborative text).

Practice

170.1 basic With N=5 replicas, which (W, R) pairs guarantee reads see the latest write? Which favours fast writes?

Any pair with W+R>5: (3,3), (4,2), (5,1), (2,4), (1,5). (1,5) gives the fastest writes and the slowest reads; (5,1) is the opposite.
